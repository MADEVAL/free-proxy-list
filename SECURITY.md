# Security policy

## Scope

This repository publishes plain-text proxy lists assembled from public sources. It stores no
user data, no accounts, no cookies, no analytics and no tracking of any kind. The files are
rebuilt automatically every day; the previous snapshot is replaced.

## Reporting privacy, security or abuse issues

Send reports to **GLOBUS.studio**:

- [globus.studio](https://globus.studio)
- [hello@globus.studio](mailto:hello@globus.studio)

Include the affected URL, a timestamp and a short description. We aim to answer within three
business days.

## Takedown requests

If your host, source or infrastructure appears in these lists and you want it removed, write to
the address above. Entries are dropped on the next build, and the source is excluded from the
pipeline when the request is about the source itself.

## Safe harbour

We do not run the listed proxies, do not control them and cannot confirm what they do. Treat every
address as untrusted input. Lists are provided "as is", without warranty of any kind, under the MIT
license in [LICENSE](LICENSE).
