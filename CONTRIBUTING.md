# Contributing

This repository is generated automatically. Every file except `README.md`, `LICENSE`, `SECURITY.md`,
`CONTRIBUTING.md` and `CODE_OF_CONDUCT.md` is overwritten on each daily build, and history is a single
snapshot commit. Pull requests that edit list data will be lost - please do not open them.

## What is welcome

- **Broken or dead sources.** Open an issue with the source URL and the affected list file.
- **Wrong entries.** Report the exact line, the file and why it is wrong (reserved range, invalid port,
  duplicate, non-proxy scheme).
- **Security, privacy and takedown requests.** Do not open a public issue - use the contacts in
  [SECURITY.md](SECURITY.md).

## Pull requests

Small fixes to the text files (`README.md`, this file, security policy) are accepted. Anything that
changes proxy data belongs in the private build pipeline, not here.
